# Helper card: <helper name>

*The one-page contract between the helper, its users, and its owner. If a field is hard to fill, the design is not finished.*

| Field | Answer |
|---|---|
| **Job** | One sentence: what this helper does |
| **Users** | Who uses it, and how many |
| **Trigger** | What starts it (an email arrives, a form is submitted, a person asks) |
| **Inputs** | What it receives, and from where |
| **Output** | What it produces, in what format, delivered where |
| **Pattern** | Single helper / chain with checks / router / parallel review / draft and critique / agent with tools |
| **Autonomy level** | L1 suggest / L2 draft for review / L3 act with approval / L4 act and report |
| **Checkpoints** | Where a person reviews, who, and what they check |
| **Knowledge and data** | Sources it uses, with sensitivity class |
| **Tools and permissions** | Systems it can read, systems it can write, and at what level |
| **Out of scope** | What it must not do or attempt |
| **Escalate when** | The situations where it stops and hands the case to a person |
| **Risk tier** | Low / medium / high, and the required controls |
| **Success thresholds** | From Step 4 |
| **Owner and backup** | Names |
| **Platform** | Where it runs |
| **Version** | v0.1, date |
