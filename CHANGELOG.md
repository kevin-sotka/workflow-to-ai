# Changelog

## 1.0.0 (2026-11-22)

First public release.

- Six gated steps (Find, Shape, Source, Fund, Build and Test, Prove) with the four Meatbag Method moves (Pick, Prompt, Prune, Ritual) inside them
- Six modes: quick pass, full build, portfolio, check-up, facilitator, resume
- Reference files for each step, plus governance, platforms, ten function playbooks, facilitation, and a worked example
- Templates for the running document, step table, scorecard, ROI inputs, helper card, helper instructions, eval set, judge prompt, and build brief
- Four standard-library scripts: workflow map, opportunity scoring, ROI calculator, eval report
- A complete illustrative example in `examples/finance-vendor-inquiries`
